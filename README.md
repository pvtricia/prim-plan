# PRIM-PLAN.

Aplicație web pentru organizarea filmelor preferate, inspirată de Goodreads.
Utilizatorii pot descoperi filme, își pot crea o colecție personală și pot ține
evidența titlurilor văzute sau pe care doresc să le vadă.

Aplicația nu este o platformă de streaming.

## Pagini
- Acasă (`index.html`)
- Explorează (`catalog.html`)
- Colecția mea (`colectia-mea.html`)
- Profil (`profil.html`)
- Administrare (`admin.html`)

## Tehnologii
- HTML5
- CSS3 (`css/style.css`)
- Bootstrap 5
